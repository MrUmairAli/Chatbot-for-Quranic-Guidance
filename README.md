# Chatbot for Quranic Guidance

## About
This is an AI-powered chatbot designed to provide guidance 
from the Holy Quran. Users can ask questions and receive 
relevant answers and references directly from Quranic verses.

Built with Python, it features a simple GUI interface making 
it easy for anyone to seek Quranic knowledge.

## Features
- Ask questions in natural language
- Get answers referenced from the Quran
- Simple code and clean anwsers
